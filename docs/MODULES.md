# 功能分组与范围

公开版以单个完整应用仓库保存依赖关系，不拆成多个无法独立启动的仓库。

1. **目录与渠道**：Model、Sku、Channel、别名和竞品映射的维护。边界：不携带原始业务映射与访问凭据。
2. **价格采集与校验**：适配器、采集运行记录、币种、分期、促销、异常标记及重复写入保护。边界：适配器存在不代表所有线上渠道当前可用。
3. **竞品矩阵与趋势**：最新报价、跨渠道对比、日历历史与趋势展示。边界：不得把虚构演示数据称为真实市场洞察。
4. **预警与新鲜度**：规则引擎、告警流、抓取健康和价格覆盖率。边界：验证不触发真实邮件或 Slack。
5. **参数与导出**：参数表解析、芯片排名、Excel 导出及可选能源标签接口。边界：原始业务工作簿与标签附件未提供给公开版。
6. **权限与工程验证**：身份认证、配置、部署模板、测试与 CI。边界：测试通过不能替代生产安全审计。

每个后续任务围绕一个明确行为改进，使用真实提交、测试和更新说明作为验收证据。首个导入提交包含原有六个模块，不将已有功能的导入伪装成新开发。
