# 公开版脱敏记录

输入是用户提供的既有项目源码压缩包。原始压缩包与提取副本保留在本地，未上传；本记录不包含原始凭据值或部署地址。

## 处理

- 不分发原始业务数据、HTML 报告、历史内部文档、截图、PDF/SVG 能源标签。
- 不导入 macOS 资源叉元数据、历史维护/排障脚本、候选链接 JSON、原始品牌种子脚本。
- 删除私有渠道—机型 PDP 映射表，公开模块保持空映射接口。
- 默认品牌与账号替换成演示标识；部署域名与本机路径不进入公开副本。
- 取消个人桌面参数表自动发现，使用环境变量和可选本地演示文件。
- 不上传 `.env`、数据库、工作簿、日志、依赖目录和构建产物；提供空白配置模板。
- 调度与 SPA 抓取默认关闭，演示渠道禁用；测试期间不发送邮件或 Slack。
- 修复未配置密码时可能使用占位值登录的问题；未配置密码必须拒绝登录。
- 演示数据重新生成，不对真实业务报价进行伪装或替换后冒充市场数据。

## 边界

保留公开站点适配器的域名和解析逻辑以展示工程结构；它们不包含授权 cookie 或账户凭据。公开版未验证真实站点的当前适配兼容性。品牌替换可能降低真实网页匹配适用性，离线验证只说明样例范围内行为。

`scan_public.py` 扫描跟踪文件中的本机路径、部分凭据模式、非演示邮箱及禁止的业务附件；它不是全面 DLP、许可证审查或安全认证。生产部署还需独立评审权限、日志、速率限制和依赖风险。
