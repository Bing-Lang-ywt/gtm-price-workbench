# 虚构参数工作簿

2026-10-02，Issue #5。在已安装后端依赖的环境中，从 backend 目录运行：

```sh
python -m app.demo_parameters demo_parameters.xlsx
```

输出包含「东北欧产品参数表」的 19 列产品数据（2 个机型）、「芯片天梯图」的 7 列芯片数据（3 个芯片），以及明确的虚构数据声明。芯片输入故意无序，现有解析器按分数降序、同分排名升序展示。产品芯片字段包含多行样例，解析器取第一行名称。

启动后端前设置 `PARAMS_XLSX_PATH` 指向生成文件；路径仅保存在本地配置中。通过已鉴权的参数接口或现有参数页面读取。也可将文件生成在现有默认兜底位置 `backend/data/demo_parameters.xlsx`，需自行先建立 data 目录；兜底文件的陈旧提示沿用现有逻辑。

目标目录必须已存在，扩展名必须是 .xlsx。已存在文件及符号链接均拒绝覆盖，CLI 失败退出码为 2，不回显本机路径。写入使用独占创建以避免检查与创建之间的覆盖竞态。磁盘写入失败可能留下不完整新文件，需本地检查。

所有名称、价格、规格、发布日期及性能分数均为虚构，不代表真实产品或排名。工具不读取原始业务表、不访问数据库、不抓取、不通知。输出被 Git 忽略，禁止上传工作簿。

验证：临时目录中生成后直接交给现有产品和芯片解析器，核对值及排序；验证普通文件、符号链接保护与 CLI 错误。完整后端离线回归 211 项通过。
